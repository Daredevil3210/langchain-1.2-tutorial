# v0.7.0 - RAG 文档切分与嵌入模型

## 新增内容

- 新增 `chapter10-RAG/02-文档切分器.ipynb`，介绍 `split_text()`、`create_documents()` 与 `split_documents()`，演示字符、递归字符、Token、语义、HTML 标题、代码与 Markdown 切分。
- 新增 `chapter10-RAG/03-文档嵌入模型.ipynb`，演示 CLOSEAI / 硅基流动模型初始化、`embed_query()` 单句向量化及 `embed_documents()` 批量文本和 CSV 文档向量化。
- 同步文档加载器的运行记录，更新 README 的项目结构、章节内容、RAG 依赖和环境变量说明。

## 运行说明

- 基础依赖之外，按示例安装 RAG 依赖，或使用 `pip install -r requirements_full.txt`。
- 语义切分与在线嵌入示例需要在本地 `.env` 配置对应平台的 API Key 和 Base URL；MinerU 在线解析另需 `MINERU_API_TOKEN`。
- 文档加载器保存的 Word 示例输出包含缺少 `unstructured` 的报错，安装相关依赖后需重新运行。
- `.env` 继续由 Git 忽略，凭据不包含在本次发布中。
