# v0.8.0 - Milvus 与客服知识库实战

## 新增内容

- 新增 `chapter10-RAG/04-Milvus的基本使用.ipynb`：数据库与集合的创建、查询和删除，文档嵌入、向量写入、flush、统计信息、迭代查询、主键查询与相似度检索。
- 新增 `chapter10-RAG/05-案例：Atguigu Assistant客服知识库.ipynb`：读取 `knowledge.txt`，切分文档，通过硅基流动嵌入模型生成向量并写入 Milvus，检索相关上下文，再由 DeepSeek Agent 生成回答。
- 更新 README 的项目结构、章节介绍、依赖和运行配置。

## 修正

- 客服案例的 `generate_answer()` 将实际问题 `query` 传给检索函数，修正误传 Python `str` 类型的问题。
- 移除客服案例中未使用的 `scripts.regsetup` 导入，避免依赖本机额外模块。

## 运行说明

- 默认 Milvus 地址为 `http://localhost:19530`；请先启动服务并安装所需依赖，完整依赖清单见 `requirements_full.txt`。
- 配置本地 `.env` 中的 `SILICONFLOW_API_KEY` / `SILICONFLOW_BASE_URL` 和 `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL`；`.env` 不包含在提交和发布中。
- 示例集合使用 1024 维向量及 `COSINE` 相似度。请使用专用练习数据库：基础教程含删除演示，客服案例会删除并重建同名集合。
- 基础教程运行删除数据库单元格后，需重新创建数据库再继续；在线模型名称应按账号支持情况配置。

## 验证范围

- 两个新增 Notebook 的格式、代码单元语法和本地素材路径检查。
- 使用模拟嵌入模型、Milvus 和 Agent 验证问题到检索、上下文到回答生成的参数传递。
- 提交文件的敏感文件与凭据扫描；未连接真实 Milvus 或调用在线模型进行端到端验证。
